☁️ Firebase Cloud Sync

এই সংস্করণে Google Drive backup-এর বদলে Firebase Cloud Firestore ব্যবহার করা হবে। একই Google Account দিয়ে ফোন ও ল্যাপটপে Sign in করলে একই হিসাব cloud-এ থাকবে এবং পরিবর্তনগুলো স্বয়ংক্রিয়ভাবে sync হবে।
Firebase: সংযুক্ত নয়
ইন্টারনেট থাকলে হিসাব Firebase-এ সংরক্ষণ হবে। ইন্টারনেট না থাকলেও এই ডিভাইসে local copy থাকবে।
প্রথমবার সেটআপ
1. Firebase Console-এ একটি project তৈরি করুন।
2. Web app যোগ করে পাওয়া Firebase config এই HTML-এর FIREBASE_CONFIG অংশে বসাতে হবে।
3. Authentication → Sign-in method থেকে Google চালু করুন।
4. Firestore Database তৈরি করুন।
5. Firestore Security Rules-এ authenticated user-এর নিজের shops/{uid} document-এ access দিন।
6. তারপর GitHub Pages-এ এই index.html আপলোড করুন।

নোট: Firebase config গোপন password নয়, তবে Firestore Security Rules অবশ্যই ঠিকভাবে সেট করতে হবে। Firebase-এর Authentication + Firestore + Security Rules ব্যবহার করাই নিরাপদ পদ্ধতি।
