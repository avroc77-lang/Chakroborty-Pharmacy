☁️ Google Drive + Google Account

একবার Google account দিয়ে Connect করলে এই সফটওয়্যার আপনার হিসাবের backup ওই account-এর Google Drive-এ রাখতে পারবে। একই account দিয়ে অন্য ফোন/ল্যাপটপে খুলে backup Restore/Sync করা যাবে।
Google Account: সংযুক্ত নয়
ইন্টারনেট থাকলে নতুন/পরিবর্তিত হিসাব Google Drive-এর একটি backup file-এ আপডেট হবে।
প্রথমবার সেটআপ
1. Google Cloud Console-এ একটি OAuth Web Client ID তৈরি করতে হবে।
2. আপনার সফটওয়্যারের HTTPS ওয়েবসাইটের domain/JavaScript origin সেখানে যোগ করতে হবে।
3. Client ID এখানে একবার বসিয়ে Connect করুন।
4. Google account অনুমতি দিলে Auto Backup চালু করুন।
5. অন্য ডিভাইসে একই website খুলে একই Client ID দিয়ে একই Google account Connect করে Drive থেকে Sync/Restore করুন।
